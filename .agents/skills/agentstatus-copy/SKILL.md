# AgentStatus copy

Multi-category copywriter for AgentStatus (public brand).  
Pair with `agentstatus-design` for visual rules.  
`agentstatus-wording` redirects here for chart/UI claim craft.

**Do not use for Parallax.**

Deep refs: [voice-brief.md](voice-brief.md) · [gtm-motion.md](gtm-motion.md) · [sat-pass.md](sat-pass.md) · [examples.md](examples.md)

## Opening ritual (every run)

1. Confirm **category:** Cards | Charts | X | LinkedIn | Outreach | Rewrite | Landing  
2. If Outreach: **Signup** vs **Design-partner**  
3. Collect facts: company, `DD Mon YYYY, HH:MM UTC`, hosts cleared/failed, one host detail  
4. Draft for that category  
5. Run **SAT pass** ([sat-pass.md](sat-pass.md))  
6. Run **anti-AI pass** (hard bans below)  
7. Ship paste-ready copy only (no manifesto padding)

## Categories

### Cards
Scorecard claim, poster, evidence summary, outreach first line on the HTML.

- Claim-first: **subject** (company / “[Company]’s MCP”) + result + metric + `DD Mon YYYY, HH:MM UTC`  
- Default result verb: **completed a tool invoke** / **failed a tool invoke** (or “tool invocations”)  
- Poster: full sentences; *but* before never-connected; separate “For [Host] specifically…” when needed  
- No “MCP INDEX” eyebrow; no residential/connect/discover/run-id meta crumbs  
- Evidence: path, args, response when available  
- Never “broken”; name the failure in plain English  

**Do not** open customer-facing lines with `Cleared tools/call…` or pack `tools/call` as the hero phrase. That reads like a dashboard export. `tools/call` may appear only as an internal protocol label in methodology or evidence `code`, not as the claim voice.

### Charts
Titles, subtitles, callouts, footers.

- Steal AA: `Metric name · Higher/Lower is better` + date when relevant  
- Definition in one breath; no Arena / Pareto marketplace language  

### X
Short tagged post. Numbers and names. Cards link or ↓. No thesis sermon.

### LinkedIn
Exa warm shape. Cards do the proof. Tag company + responsible people. Same spine as X, slightly more breath OK.

### Outreach · Signup (GTM default)
Finding + scorecard link + self-serve. No meeting required. No “book a demo.”

**Locked soft close (operator):**  
`If you want to see why [host] failed and what to change, feel free to create an account at agentstatus.dev.`

Swap `[host]` for the named failure host (e.g. Cursor). Do not use “start free on…” or the fragment “Free account shows the client error…”

**Lane A notify (pre-publish) — locked shape:**  
1. Who you are (`I'm [Name] on the AgentStatus team`)  
2. What we publish, in plain English (across AI hosts; name apps). **Never** say “host matrices.”  
3. Company is up next  
4. Finding in spoken English: `[Company]'s MCP completed a tool invoke on [N] of [M] hosts, but [K] never connected.` Then a separate sentence for the partial host: `For [Host] specifically, the tools were listed but none of the [N] tool invocations went through.`  
5. Operator soft close  

Keep **tool invoke / tool invocations** on Cards, social, and outreach. Do not switch back to `cleared tools/call` packing.

**Lane A template:**  
Hey, I'm [Name] on the AgentStatus team. We publish how public MCP servers behave across AI hosts like Cursor and Claude, and [Company] is up next. On [DD Mon], [Company]'s MCP completed a tool invoke on [N] of [M] hosts, but [K] never connected. For [Host] specifically, the tools were listed but none of the [N] tool invocations went through. If you want to see why [Host] failed and what to change, feel free to create an account at agentstatus.dev.

### Outreach · Design-partner
Finding they cannot see in their own logs + offer to walk continuous monitor / Certificate. Still finding-led, not a generic pitch.

### Rewrite
Critique first (job, strongest line, what to preserve). Then rewrite. Do not slogan-restack.

### Landing
Hero / subhead / CTA. Clarity and specificity. CTAs: what they get (Submit MCP · Sign up · Cover blind spots). Still no em dashes / antithesis stacks / Fabric metaphors.

## Hard bans

1. Em dash (`—`) anywhere. Use comma, period, paren, or rewrite.  
2. Antithesis blade stacks: `It's not X, it's Y` / `Listed is not called. Called is not the job.` as the post (OK once in methodology docs only).  
3. Three or more punchy one-liners in a row (LLM cadence). Pack metrics with *and / but / though / because / so*.  
4. “Broken” / “broken MCP” as a judgment.  
5. Excited to share / proud to announce / game-changing / finally / unlock / seamless / robust.  
6. “The only way” and absolute uniqueness claims.  
7. Fabric / mystery diner / restaurant-menu metaphors on scorecards or tagged social.  
8. Thesis dump (“Models are noisy…”) on scorecard posts (thought piece category only).  
9. Book a demo as default CTA for the scorecard loop.  
10. Identity / favor openers; Parallax voice.  
11. **`Cleared tools/call` / `Failed tools/call` as the default claim or social lede.** Use *completed a tool invoke* / *failed a tool invoke* (with a subject). Protocol name `tools/call` stays in evidence/methodology only unless the user explicitly asks for it.

---

## Rhythm

- One fact → short sentence is fine.  
- Two+ metrics → **one compound sentence** (or two at most).  
- Contrast after a partial success (list worked, invoke failed) → prefer **but**, not *then* (SAT transition fit).  
- Sequence only → *then* / *after*.  

---

## SAT pass (required before ship)

See [sat-pass.md](sat-pass.md). Minimum:

1. Transition matches logic (*but* vs *then* vs *and* vs *because*).  
2. Agreement, boundaries, no comma splice.  
3. Concision: every clause carries a fact.  
4. No em dashes.

---

## Product language (steal)

Verbs: reach, negotiate, list, call, score, pin, walk, cover, submit, validate.  
Frame: outside-in / user-side / residential (not datacenter ping) / cross-host.  
Stack: URL → dialect → catalog → tools/call → did the result look like the job.  
Public brand on assets: **AgentStatus** / agentstatus.dev.

AA steal for charts only: claim-first, metric · direction, honest non-claims.  
AA leave: Elo/Arena, Pareto “attractive quadrant,” soft “understand the AI landscape…”
